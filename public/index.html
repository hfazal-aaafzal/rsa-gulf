Applicants and their documents, saved on the server. Only you and invited editors can see this section.

This holds personal data. Do not give editor access to anyone who should not see passport or CNIC copies.

Data handling process (6 steps)
  1. Record: when a message or call arrives, tap Add applicant. Paste the WhatsApp message to fill the form.
  2. Identify: check the passport and CNIC against the person. Attach clear scans to the same record.
  3. Complete: tick each document received. The card shows what is still missing.
  4. Track: change the status at every stage and set a follow-up date. Each change is written to the history.
  5. Back up: save a backup file at least once a week and keep it in a safe place.
  6. Close: when someone is not proceeding, delete the record and its files if they ask, or after the retention period you decide.
Last backup: never
